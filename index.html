⚡ Fórmulas Power Fx Implementadas en la App

Lógica de control para gestión de estados resolutivos y bloqueos.

// 1. Búsqueda y Extracción del Registro (LookUp)

Set(
  varTicketActual,
  LookUp(
    'Fact_Solicitudes_Lists',
    Ticket_ID = TextInputSearch.Text
  )
);

// 2. Validación y Formato de Estados de Cierre (Switch)

Switch(
  varTicketActual.Estado,
  "Completada", Color.Green,
  "Cerrada - Bloqueada", Color.Red,
  "En Curso", Color.Blue,
  Color.Gray
);

// 3. Inserción de Notas con Auditoría (Patch)

Patch(
  'Fact_Solicitudes_Lists',
  varTicketActual,
  {
    Ultima_Nota: TextInputNota.Text,
    Fecha_Ultimo_Estado: Now(),
    Modificado_Por: User().FullName
  }
);

Regla de Gobernanza de Datos: Al marcar un ticket como Cerrada - Bloqueada, se remueve automáticamente de la cola activa de trabajo (*Work In Progress*), evitando que altere los tiempos medios de resolución (MTTR) de los requerimientos viables.
